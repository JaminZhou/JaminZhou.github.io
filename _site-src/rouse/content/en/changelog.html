Rouse Changelog

Release notes for the Mac App Store version of Rouse. This page keeps the public version history short and user-focused.

1.12.0 Latest

Added custom wake durations and made Launch at Login more reliable.

  • Choose any duration from 5 minutes to 24 hours in 5-minute steps.
  • Use the same saved duration from Dashboard or the menu-bar Quick Panel.
  • When macOS requires login-item approval, Rouse opens the right System Settings page and reports registration errors clearly.
1.11.0

Added optional closed-lid support through a separately installed open-source Helper.

  • Connects to the separately installed, open-source Rouse Closed-Lid Helper; the Mac App Store app alone does not change system sleep settings. See the setup and recovery guide.
  • Uses the Helper only during active Rouse wake sessions and releases it when the session ends.
  • Shows installation, approval, compatibility, and recovery status in Settings.
1.10.0

Made launch at login easier and expanded language support.

  • Added an optional one-time prompt to keep Rouse ready after restart or sign-in.
  • Shows the real macOS login-item status and opens Login Items when approval is needed.
  • Added Brazilian Portuguese across the app, feedback form, website, and App Store.
  • Added a Mexican Spanish App Store listing with matching screenshots.
1.9.3

Stabilized menu bar session reconfiguration.

  • Made switching between indefinite and timed sessions steadier in Quick Panel.
  • Kept timed duration controls clickable while the menu bar panel is open.
  • Improved direct reconfiguration of active sessions.
1.9.2

Polished localized support drafts and i18n guardrails.

  • Localized the Email Support draft subject, prompts, version details, macOS details, and entry point labels across every current Rouse locale.
  • Improved user-facing error copy so app errors stay clear and localized instead of falling back to technical descriptions.
  • Added static i18n checks to lint, tests, CI, and the PR checklist so future user-facing text leaks are caught earlier.
Earlier releases — 1.9.1 to 1.0.0
1.9.1

Enabled optional Support Rouse purchases.

  • Enabled optional one-time support purchases in the Mac App Store version.
  • Kept every core wake-control feature free, including timed sessions, display sleep control, battery-aware rules, and the official rouse CLI.
  • Added approved Support Rouse, Buy a Coffee, and Buy Two Coffees products for users who want to support ongoing development.
1.9.0

Added French, Spanish, and Korean localizations.

  • Added French, Spanish, and Korean app localizations.
  • Added matching Mac App Store metadata and screenshots for the new languages.
  • Updated localization tests and screenshot tooling so future translations stay complete.
  • Kept wake sessions focused on the menu bar, Dashboard, display sleep, battery rules, and the official rouse CLI.
1.8.0

Added German localization and an App Language shortcut.

  • Added German localization across Rouse and the Mac App Store listing.
  • Added a Settings shortcut for opening macOS Language & Region when you want to choose a per-app language for Rouse.
  • Cleaned up the Dashboard header and made command line setup a lighter entry point.
  • Centralized localization lookup for more consistent app, test, and screenshot behavior.
1.7.0

Added the official rouse command line interface.

  • Added a bundled rouse CLI for Terminal, shell scripts, and local automation workflows.
  • Let command line tools start, stop, inspect status, open the Dashboard, and manage display sleep while Rouse.app remains the session owner.
  • Added Command Line setup guidance in Settings, including permission context and recovery steps.
  • Improved Dashboard access from the menu bar and polished support actions in About Rouse.
1.6.0

Improved accessibility across the app.

  • Added clearer VoiceOver labels, values, and hints in Dashboard, Quick Panel, Settings, About, and the menu bar control.
  • Improved keyboard navigation in Quick Panel, Settings, and About.
  • Made Dashboard respect more macOS display accessibility settings, including Reduce Motion, Reduce Transparency, Increase Contrast, and Differentiate Without Color.
  • Refined menu bar icon alignment.
1.5.0

Change display sleep while a session is already running.

  • Let you adjust display sleep while a session is active, so you can keep the screen awake only when you need it.
  • Included behind-the-scenes reliability improvements for the release flow and session handling.
1.4.0

Polished the dashboard layout.

  • Refined dashboard layout and spacing for a cleaner, calmer presentation.
  • Improved readability and balance for longer dashboard content.
1.3.0

Added App Shortcuts and refined the release experience.

  • Added App Shortcuts for starting a session, starting a timed session, stopping a session, and opening the Dashboard.
  • Refined Dashboard transitions and layout behavior for longer and localized text.
  • Added clearer feedback and support entry points, and updated the menu bar icon.
1.2.0

Added Japanese and Chinese localization support.

  • Added Japanese, Simplified Chinese, and Traditional Chinese localizations.
  • Refreshed Dashboard and Quick Panel copy to match the current product language.
  • Improved dashboard placement behavior and session status reliability.
1.1.0

Added optional tip jar support.

  • Added a "Support Rouse" section in the About window with tip jar purchases and Restore Purchases.
  • Improved internal tooling for App Store Connect review asset management.
1.0.0 First release

Initial Mac App Store release.

  • Introduced quick menu bar wake controls and a calm dashboard for deeper control.
  • Added indefinite and timed wake sessions, display sleep control, battery protection, and launch at login.
  • Included timed session restore behavior after relaunch or system wake.
