Solução por Terminal para Repouso ao Fechar o MacBook

Última atualização: 20 de abril de 2026

Esta página documenta uma solução avançada de Terminal para controlar manualmente o repouso ao fechar a tampa do MacBook, fora da versão do Rouse na Mac App Store.

Esta é uma solução por Terminal, não uma API oficial do macOS nem um recurso do Rouse na Mac App Store. Ela altera um ajuste de energia do sistema e exige privilégios de administrador. O comportamento pode variar entre modelos de Mac e versões do macOS.

A versão da Mac App Store não pode oferecer isso como recurso porque a solução depende de alterações de energia com pmset e privilégios de administrador, fora dos limites normais do App Sandbox.

Comandos rápidos

Adicione esta função ao seu ~/.zshrc ou outro perfil de shell:

rouse-lid() {
  case "$1" in
    on)
      sudo pmset -a disablesleep 1
      pmset -g | awk '/^[[:space:]]*SleepDisabled[[:space:]]/ { print "SleepDisabled =", $2 }'
      ;;
    off)
      sudo pmset -a disablesleep 0
      pmset -g | awk '/^[[:space:]]*SleepDisabled[[:space:]]/ { print "SleepDisabled =", $2 }'
      ;;
    status)
      pmset -g | awk '/^[[:space:]]*SleepDisabled[[:space:]]/ { print "SleepDisabled =", $2 }'
      ;;
    *)
      echo "usage: rouse-lid {on|off|status}"
      return 1
      ;;
  esac
}

Recarregue seu shell e use rouse-lid on, rouse-lid offe rouse-lid status.

O que realmente faz

  • rouse-lid on corre sudo pmset -a disablesleep 1.
  • rouse-lid off restaura o sono normal com sudo pmset -a disablesleep 0.
  • rouse-lid status imprime o atual SleepDisabled estado em um formato legível.
  • O caso de uso desta página é o repouso com a tampa do MacBook fechada, não um controle genérico de repouso para desktops.

Como disablesleep=1 impede tanto o repouso por inatividade quanto o repouso com a tampa fechada, o Mac continuará ativo mesmo sem uso. Execute rouse-lid off assim que terminar.

Limites

  • Esta é uma solução alternativa avançada para o terminal, não um recurso do produto enviado.
  • Afeta o sono do sistema globalmente, não apenas o sono com a tampa fechada.
  • É separado da versão do Rouse na Mac App Store.
  • A versão da Mac App Store não pode incluir esse caminho como um recurso compatível.
  • O ajuste persiste após reinicializações. Se você esquecer de executar rouse-lid off, o Mac continuará ignorando o repouso depois de reiniciar.
  • Prefiro rouse-lid off assim que terminar.

Como removê-lo

  • Se o estado atual ainda mostrar SleepDisabled = 1, corra rouse-lid off primeiro. Se você já removeu a função, você pode executar sudo pmset -a disablesleep 0 diretamente.
  • Remova o rouse-lid() função de ~/.zshrc ou qualquer perfil de shell que você usou e recarregue seu shell.

Sobre esta página

A versão do Rouse na Mac App Store respeita os limites do App Sandbox. Esta página documenta uma solução de Terminal para usuários avançados que sabem alterar os ajustes de energia do sistema. A função de shell rouse-lid mostrada aqui é um auxiliar independente salvo no perfil do shell; ela não faz parte da CLI da versão do Rouse na Mac App Store.
