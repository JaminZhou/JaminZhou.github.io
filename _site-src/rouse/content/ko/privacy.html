Rouse 개인정보 처리방침

시행일: 2026년 4월 26일

이 개인정보 처리방침은 Mac App Store 버전을 포함한 macOS용 Rouse에 적용됩니다.

요약

Rouse는 Mac에서 로컬로 동작합니다. 계정, 광고, 분석, 추적 SDK 없이 빠른 메뉴 막대 제어, 더 자세한 대시보드, 공식 명령줄 인터페이스를 제공합니다.

Rouse가 수집하지 않는 정보

  • 계정 정보 없음
  • 광고 식별자 없음
  • 타사 분석 데이터 없음
  • 위치 데이터 없음
  • 연락처, 사진 보관함, 마이크, 카메라 데이터 없음

기기에 로컬로 저장되는 정보

Rouse는 예상대로 동작하기 위해 앱 환경설정을 Mac에 로컬로 저장합니다. 선호 세션 길이, 디스플레이 잠자기 방지, 배터리 보호 설정, 로그인 시 실행, 이 Mac의 Supporter 상태 등이 포함될 수 있습니다. 이 정보는 기기에 남으며 앱이 개발자에게 보내지 않습니다.

네트워크 활동

Mac App Store 버전의 Rouse는 핵심 깨움 제어 기능을 로컬로 수행합니다. 메뉴 막대 제어, 대시보드, 세션 시작, 규칙 관리를 위해 로그인이나 원격 계정이 필요하지 않습니다. 선택적 지원 구입을 사용하는 경우 Apple의 StoreKit과 App Store 서비스를 사용합니다.

명령줄 통신

공식 rouse 명령줄 도구는 Terminal 명령, 셸 스크립트, 자동화 도구가 깨움 세션을 제어할 수 있도록 Rouse.app과 로컬로 통신합니다. 이 통신은 macOS가 관리하는 개인 공유 컨테이너를 사용할 수 있으며 문서나 다른 앱 데이터를 읽지 않습니다.

지원 요청

이메일로 문의하면 사용자가 보내기로 선택한 정보는 요청에 답변하고 지원 품질을 개선하는 데만 사용됩니다. 피드백 양식은 익명 제출 또는 후속 연락용 이메일 포함을 선택할 수 있습니다.

타사 서비스

타사 이메일 제공업체나 외부 서비스를 통해 지원에 연락하면 해당 서비스의 약관과 개인정보 관행도 적용될 수 있습니다. 현재 피드백 양식은 Tally를 통해 제공됩니다.

아동 개인정보

Rouse는 아동을 대상으로 하지 않으며 앱은 아동의 개인정보를 고의로 수집하지 않습니다.
