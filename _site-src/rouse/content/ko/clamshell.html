덮개 닫힘 지원과 선택형 도우미

마지막 업데이트: 2026년 7월 23일

출시 전: 아직 서명된 도우미 다운로드가 없습니다. 서명되지 않은 빌드는 설치하지 마세요. 실제 Mac 안전성 검증이 끝난 뒤에만 서명 및 공증된 DMG를 제공합니다.

Mac App Store 버전의 Rouse는 계속 샌드박스 안에서 실행되며 root로 실행되지 않습니다. 공개 macOS API로 유휴 시스템 및 디스플레이 잠자기를 막을 수 있지만, 덮개를 닫은 상태의 작동에는 일반 Mac App Store 앱이 수행할 수 없는 시스템 전체 전원 변경이 필요합니다.

예정된 사용 흐름

  1. 별도로 배포되는 Rouse Closed-Lid Helper를 응용 프로그램 폴더에 설치합니다.
  2. 시스템 설정에서 백그라운드 서비스를 승인합니다. Apple Service Management를 사용하며 Rouse는 관리자 암호를 수집하지 않습니다.
  3. Rouse에서 기본값이 꺼진 선택 옵션을 켭니다. Rouse 세션이 활성 상태일 때만 짧은 임대를 갱신합니다.

권한 구성 요소의 소스는 검토할 수 있도록 GitHub에 공개되어 있습니다.

안전 모델

  • 데몬은 고정된 상태, 임대, 해제, 복원 작업만 제공하며 셸이나 일반 명령 실행 기능은 제공하지 않습니다.
  • 임대는 90초이며 최대 120초입니다. Rouse가 종료되거나 연결이 끊기거나 갱신을 멈추면 자동으로 만료됩니다.
  • 변경 전에 전원 공급원별 원래 값을 기록하고 만료, 연결 해제, 재시동, 제거 또는 정리 시 정확히 복원합니다.
  • 통신 전에 개발 팀 서명, Bundle ID, App Group 및 프로토콜 버전을 확인합니다.

출시 상태

구현은 테스트 중이지만 아직 지원되는 공개 기능은 아닙니다. Developer ID 서명, 공증, Gatekeeper 확인과 Apple Silicon 및 Intel 실제 기기에서 전원, 배터리, 재시동, 강제 종료, 데몬 장애, 업데이트, 제거 테스트를 통과해야 출시합니다. 그전에는 덮개 닫힘 작동을 보장하지 않습니다.

긴급 복구 전용

출시 후에는 먼저 도우미의 “복원 및 서비스 제거”를 사용하세요. 정리 전에 도우미와 데몬을 삭제했고 Mac이 잠자기 상태로 들어가지 않는 경우에만 관리자가 기본값을 복원할 수 있습니다.

sudo pmset -a disablesleep 0

이 긴급 명령은 다른 도구가 설정한 기본값이 아닌 값을 복원할 수 없습니다. 정상 제거는 기록한 정확한 값을 복원합니다.
