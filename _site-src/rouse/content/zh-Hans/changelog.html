Rouse 更新日志

最后更新：2026 年 9 月 19 日

这里记录 Rouse Mac App Store 版本的发布说明，以简洁、面向用户的方式展示公开版本历史。

1.13.0

新增定时会话的显示器睡眠控制。

  • 可以让显示器睡眠，同时继续保持 Mac 唤醒。
  • 可以选择计时结束后继续保持唤醒，或结束保持唤醒会话。
  • 可从 Dashboard 和菜单栏管理这个行为。
1.12.1

针对最新 macOS 重建，并已在 macOS 27 上测试。

  • 使用 Xcode 27 和 macOS 27 SDK 构建。
  • 通过同时支持 Apple silicon 和 Intel 的通用版本继续支持 macOS 13 及更高版本。
  • 菜单栏控制、定时会话、显示器睡眠控制、电池保护和“登录时启动”行为保持不变。
1.12.0

新增自定义唤醒时长，并提升“登录时启动”的可靠性。

  • 可在 5 分钟至 24 小时之间按 5 分钟递增选择时长。
  • 在 Dashboard 或菜单栏快捷面板中使用同一项已保存时长。
  • macOS 要求批准登录项时，Rouse 会打开正确的系统设置页面，并明确显示注册错误。
1.11.0

新增通过单独安装的开源辅助工具实现的可选合盖支持。

  • 连接单独安装的开源 Rouse Closed-Lid Helper；Mac App Store 版不会单独更改系统休眠设置。请参阅安装与恢复指引。
  • 仅在 Rouse 唤醒会话进行时使用辅助工具，并在会话结束时释放。
  • 在设置中显示安装、批准、兼容性和恢复状态。
1.10.0

简化登录时启动设置，并扩展语言支持。

  • 新增可选的一次性引导，让 Rouse 在重新启动或登录后保持可用。
  • 显示真实的 macOS 登录项状态，并在需要批准时打开登录项设置。
  • 在 app、反馈表单、网站和 App Store 中新增巴西葡萄牙语。
  • 新增墨西哥西班牙语 App Store 页面及配套截图。
1.9.3

提升菜单栏进行中会话重新配置的稳定性。

  • 在 Quick Panel 中切换持续会话和定时会话时更加稳定。
  • 菜单栏面板打开时，定时时长控件可以稳定点击。
  • 已开启的会话现在能更可靠地直接重新配置。
1.9.2

完善本地化支持草稿和 i18n 检查。

  • 在所有当前 Rouse 语言中本地化邮件支持草稿的主题、提示、版本信息、macOS 信息和入口标签。
  • 改进用户可见错误文案，让应用错误保持清晰且本地化，而不是回退到技术描述。
  • 把静态 i18n 检查接入 lint、测试、CI 和 PR checklist，更早发现未来的未本地化文案。
1.9.1

启用可选 Support Rouse 购买。

  • 在 Mac App Store 版本中启用可选的一次性支持购买。
  • 所有核心常亮控制功能仍然免费，包括定时会话、显示器睡眠控制、电量规则和官方 rouse CLI。
  • 新增已获批准的 Support Rouse、Buy a Coffee 和 Buy Two Coffees 商品，供愿意支持持续开发的用户选择。
1.9.0

新增法语、西班牙语和韩语本地化。

  • 新增法语、西班牙语和韩语应用本地化。
  • 为新语言补齐对应的 Mac App Store 元数据和截图。
  • 更新本地化测试和截图工具，降低后续新增语言时漏翻的风险。
  • 常亮会话继续聚焦菜单栏、Dashboard、显示器睡眠、电量规则和官方 rouse CLI。
1.8.0

新增德语本地化和 App Language 快捷入口。

  • 为 Rouse 应用和 Mac App Store 商品页新增德语本地化。
  • 在设置中加入快捷入口，方便需要为 Rouse 单独选择语言时打开 macOS Language & Region。
  • 简化 Dashboard 顶部区域，并让命令行设置入口更轻量。
  • 集中本地化 lookup，让应用、测试和截图脚本的本地化行为更一致。
1.7.0

新增官方 rouse 命令行工具。

  • 新增内置 rouse CLI，可用于 Terminal、shell 脚本和本地自动化流程。
  • 命令行可以启动、停止、查看状态、打开 Dashboard，并控制显示器防睡眠设置；会话仍由 Rouse.app 持有。
  • 在设置中新增命令行引导，说明权限用途和拒绝后的恢复方式。
  • 改进了菜单栏打开 Dashboard 的体验，并打磨 About Rouse 中的支持操作。
1.6.0

改进了全应用的辅助功能支持。

  • 在 Dashboard、Quick Panel、Settings、About 和菜单栏控制中提供更清晰的 VoiceOver 标签、数值和提示。
  • 改进 Quick Panel、Settings 和 About 的键盘导航。
  • Dashboard 现在会更好地响应 macOS 显示辅助功能设置，包括 Reduce Motion、Reduce Transparency、Increase Contrast 和 Differentiate Without Color。
  • 调整菜单栏图标对齐。
1.5.0

现在可以在会话进行中直接调整显示器常亮设置。

  • 无需停止当前会话，也可以切换显示器常亮设置，只在需要时保持屏幕点亮。
  • 同时改进了发布流程相关的稳定性和会话处理的可靠性。
1.4.0

进一步打磨 Dashboard 的布局体验。

  • 优化 Dashboard 的布局与间距，让整体界面更简洁、更从容。
  • 改进较长内容场景下的可读性与视觉平衡。
1.3.0

新增 App Shortcuts，并进一步打磨 Dashboard 体验。

  • 新增 App Shortcuts，可直接开始会话、开始定时会话、停止会话，或打开 Dashboard。
  • 优化 Dashboard 的状态切换和布局稳定性，长文案和多语言场景下也更清晰。
  • 补充了更直接的反馈与支持入口，并更新了更易识别的菜单栏图标。
1.2.0

新增日语和中文本地化支持。

  • 新增日语、简体中文和繁体中文本地化。
  • 更新 Dashboard 与 Quick Panel 文案，使其与当前产品表达保持一致。
  • 改进 Dashboard 定位行为与会话状态稳定性。
1.1.0

新增可选的打赏支持。

  • 在 About Rouse 窗口中加入了 “Support Rouse” 区块，提供打赏选项和 Restore Purchases。
  • 改进了 App Store Connect 审核素材管理的内部工具。
1.0.0

Mac App Store 首次发布。

  • 提供菜单栏快速防休眠控制，以及用于更深入控制的简洁 Dashboard。
  • 支持不限时和定时会话、显示器睡眠控制、电池保护和登录时启动。
  • 支持在重新启动应用或系统唤醒后恢复定时会话。
