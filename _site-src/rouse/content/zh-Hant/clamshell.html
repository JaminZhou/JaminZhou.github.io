目前狀態

闔蓋支援與可選輔助工具

最後更新：2026 年 7 月 26 日

Helper v1.0.0 已發佈：請只從官方 GitHub Release下載 Developer ID 簽署、Apple 公證的 DMG。App 內整合需要 Rouse 1.11 或更新版本；安裝前請確認 Mac App Store 版本。

Mac App Store 版 Rouse 會繼續在沙盒中執行，也不會以 root 身分執行。它可透過 macOS 公開 API 阻止閒置系統睡眠和顯示器睡眠；但闔蓋運作需要系統層級電源修改，一般 Mac App Store App 無權直接完成。

安裝與使用

  1. 把獨立發佈的 Rouse 闔蓋輔助工具 放入「應用程式」檔案夾。
  2. 在「系統設定」中核准它的背景服務。輔助工具使用 Apple Service Management 框架，Rouse 不會收集管理員密碼。
  3. 在 Rouse 中開啟預設關閉的可選開關。只有 Rouse 喚醒工作階段作用中時，才會續期短租約。

特權元件原始碼在 GitHub 上的 Rouse Closed-Lid Helper 公開供檢視；簽署下載位於官方 v1.0.0 Release。

安全設計

  • 守護程式只提供固定的狀態、租約、釋放和還原操作，不提供 shell 或通用指令執行能力。
  • 單次租約為 90 秒，上限 120 秒。Rouse 結束、連線中斷或停止續期後，覆寫設定會自動到期。
  • 修改前會分別記錄每種電源來源的原始值；租約到期、連線中斷、重新啟動、移除或主動清理時，會還原這些精確值。
  • 通訊前會驗證開發團隊簽章、Bundle ID、App Group 和協定版本。

發佈狀態

Helper v1.0.0 已簽署、公證並公開發佈。已驗證簽署版 Rouse TestFlight 整合、Universal 和 Rosetta 建置、有限租約還原、設定精確還原，以及 Apple 晶片接通電源時的闔蓋運作。根據已記錄的 v1.0.0 版本例外，電池與電源切換、主動睡眠和低電量保護、守護程式強制重新啟動、完整重新啟動與關機、乾淨帳號下的公開產物驗證、原地升級仍為延期且未記為通過。查看準確證據和延期清單。

還原與移除

應優先使用輔助工具中的「還原並移除服務」。如果輔助工具和守護程式在清理前已被刪除，而且 Mac 無法正常睡眠，管理員可以還原預設值：

sudo pmset -a disablesleep 0

這條緊急指令無法還原其他工具設定的非預設值；正常移除輔助工具時會還原先前擷取的精確值。
