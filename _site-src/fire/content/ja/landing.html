iPhone と iPad の FIRE 1.2

iPhone と iPad の 1.2 では「お気に入り」を無料で使えます。スタイル詳細のハートを押し、ギャラリーで「お気に入り」を選んでください。この端末だけに保存され、既定のスタイルや購入権限は変わりません。

iPhone・iPad・Apple Watch 版の FIRE 1.2.0 を公開しました。App Store への反映は順次行われるため、地域によっては現在も 1.1.0 と表示される場合があります。Mac 版は現在 1.1.0 で、1.2.0 への更新は審査待ちです。iOS / iPadOS 18、macOS 15、または watchOS 10 が必要です。

基本機能、iCloud 同期、22 種類のスタイルは引き続き無料で、サブスクリプションはありません。iPhone と iPad の 1.2 では「自由な日曜日」「遠い野原」「長い夏」「冬ごもり」をそれぞれ一度の購入で利用できます。Mac の 1.1 では「自由な日曜日」と「長い夏」を利用できます。コーヒーまたはサポーターバッジの購入には、現在と今後のすべてのプレミアムスタイルが含まれます。「購入を復元」で検証済みの過去の購入を確認し、対象スタイルへのアクセスを復元できます。過去のコーヒーでの応援も対象ですが、消費済みコーヒー商品の復元や返金ではありません。応援ページのコレクション用バッジには、サポーターバッジの購入が必要です。価格は App Store の表示に従います。解除してもスタイルは自動変更されません。
