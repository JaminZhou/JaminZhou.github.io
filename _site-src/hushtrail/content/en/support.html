Before you contact support

  • Hushtrail supports macOS 13 Ventura or later.
  • Confirm which folders you authorized from the Scan Locations screen.
  • If the issue involves browser privacy traces, quit the related browser before testing cleanup.
  • Do not send private browser database contents, passwords, cookies, or unredacted sensitive paths.

What to include

  • Your Hushtrail version and build number
  • Your macOS version
  • The folder category you selected, such as Caches, Logs, Preferences, Saved Application State, Application Support, or a browser profile folder
  • The scan explanation shown by Hushtrail, if it helps
  • A screenshot with sensitive file paths hidden, if useful

  • Rollback History, restore, and permanent discard behavior

  • Chrome, Chromium-family, and Firefox profile folders inside authorized roots

Frequently asked questions

  • Why does Hushtrail ask me to choose folders? The Mac App Store build is sandboxed, so it needs you to pick the folders it is allowed to inspect.
  • Does Hushtrail delete immediately? No. Eligible cleanup moves into rollback history first. Discarding a rollback archive later is permanent.
  • Why is a browser item blocked? Browser-owned data is blocked while that browser is running or when the running state is unknown.
  • Why is Firefox history scan-only? Firefox history shares places.sqlite with bookmarks, so Hushtrail does not archive that database in the current beta.
  • Where can I read the privacy policy? Visit the Hushtrail Privacy Policy.
Support requests are answered in English. Please avoid sending secrets, private database contents, or full browser profile exports.
