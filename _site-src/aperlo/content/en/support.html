Aperlo · Support

Make yourself at home.

Open images and folders

Use File → Open, drag images or a folder into the viewer, or use Finder’s Open With. If a single image has no folder permission, use Browse Folder to choose its parent folder.

Include subfolders

Enable Include subfolders in Settings → General before opening a folder. Open Recent uses the saved choice. Hidden items, symlinks and package contents are excluded.

Resume or clear history

Reopen the same folder or the same ordered group to resume its saved image. File → Open Recent and the Dock list show up to ten collections. Clear Menu removes these collections and saved positions. A missing image falls back to the first available image with a notice.

Zoom and full screen

Use Fit to Window, Actual Pixels, or zoom controls. Enter full screen with the green window control. General settings provide full-screen zoom behavior and optional click-to-advance. Enlarged images can be panned; page swipes navigate only when the whole image is visible.

Optional purchases

Settings → Support offers two repeatable tips and a one-time Supporter Badge. All viewing features are free. Restore Purchases restores an eligible badge using the same Apple Account; consumable tips cannot be restored. Prices are supplied by the App Store.

Language, appearance, and file access

English is the default; choose another supported language in General, then relaunch. Appearance can follow the system or use Light or Dark. Aperlo reads only files you authorize and needs no Full Disk Access. Rechoose a remembered location if access is unavailable. RAW, HDR and multipage-image workflows are outside the first release.
