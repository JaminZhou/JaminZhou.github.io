Aperlo プライバシーポリシー

バージョン 1.0.0 · 2026年10月4日

このポリシーは macOS 用 Aperlo と任意のサポート窓口に適用されます。開発者は Jamin Zhou です。

Aperlo は Mac 上で画像を処理します。画像、ファイル名、ファイルパス、閲覧履歴をアップロードせず、広告や分析用 SDK も含みません。設定と最近使ったファイルへのアクセス用ブックマークは Mac に保存されます。最近使った項目は「ファイル」メニューから消去できます。

任意の支援購入は Apple が処理します。Aperlo は検証済みの StoreKit 取引を確認し、サポーターバッジを表示します。カード情報を受け取ることはありません。画像閲覧機能は無料です。

フィードバックは任意です。Tally フォームを開くと、アプリのバージョン、ビルド番号、macOS のバージョン、アプリの言語が Tally に送信されます。送信後、Jamin Zhou が内容と任意のメールアドレスを受け取ります。Tally は同社のポリシーに従って技術的なリクエストデータを処理します。メールの場合は同じ情報を含む編集可能な下書きが開き、利用するメールサービスから送信するかどうかを選べます。

フィードバックはサポートへの対応にのみ使用します。返信後に元のメールと Tally のメッセージを削除し、匿名のメッセージは読んだ後に削除します。コピーや要約は保存せず、分析やマーケティング、他のデータとの関連付けには使用しません。第三者のサービス提供者には、それぞれの保存ポリシーが適用されます。削除のご依頼は me@jaminzhou.com までご連絡ください。画像やログは自動添付されません。

外部サービスとこのウェブサイト

Apple は独自のポリシーに従い、App Store の決済とアカウントサービスを提供します。Tally は任意のフォームをホストし、技術的なリクエストデータを処理する場合があります。ブラウザやメール提供者にも各自のプライバシーポリシーがあります。この静的サイトは GitHub Pages でホストされ、分析スクリプトは含みません。ホスティング提供者は技術的なアクセスログを処理する場合があります。
