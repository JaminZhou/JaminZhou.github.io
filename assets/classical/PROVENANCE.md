# Classical design resources

These files were copied byte-for-byte from the Claude Design project export
`JaminZhou portfolio redesign (4).zip` on 2026-09-01, except for the two local
font URLs in `styles.css`, which were shortened to match this production
directory layout.

- `CormorantGaramond-Variable.woff2`
- `Lora-Variable.woff2`
- `styles.css`

The font faces are licensed under the SIL Open Font License 1.1. The export did
not include its referenced license files, so the matching license texts were
added from the official Google Fonts repository on 2026-09-02:

- [`OFL-CormorantGaramond.txt`](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt)
- [`OFL-Lora.txt`](https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt)
