Inside Trailglass

From the library to the smallest detail.

Start with a session, stay with the conversation, and switch to Research when the details matter. These images use clearly labeled example sessions.

Choose what to open

Open a session file or authorize a folder through the macOS file picker. Trailglass reads supported Codex, Claude Code, Pi, and JSON records.

Browse or Research

Browse keeps the conversation readable. Research reveals the normalized event stream, tool calls, results, and warnings.

Keep the source in reach

Inspect metadata and usage details, then open Raw JSON when you need to compare an event with its original record.

Find the moment

Search messages and events, narrow the view with filters, and follow sessions as authorized files change.

Share what you choose

Export a readable transcript or save results to a location you select. Your original session files are not modified.

Try it first

Load the included sample session to explore the interface without connecting an agent or opening a private log.

Local by design

Your sessions stay on your Mac.

Trailglass processes the session files you choose locally. It does not upload their contents for analysis. It is an independent viewer, not an AI-agent service.
